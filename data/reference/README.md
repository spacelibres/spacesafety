# 参考数据归档

本目录存放**不参与渲染、但项目需要长期保留**的参考数据。与 `data/` 其他内容一样不进版本库，
用脚本重新生成或下载，本文件说明每个文件的来源与用途。

| 文件 | 来源 | 生成命令 | 用途 |
|---|---|---|---|
| `countries-110m.geojson` | [Natural Earth 1:110m admin-0](https://www.naturalearthdata.com/)（公有领域） | `npm run fetch:geo` | 国家边界与多语种国名 |

## countries-110m.geojson

**为什么不渲染了。** 早期版本在这个文件上给每个国家画一个名字标注。在以北半球 13 000 颗卫星
为主体的视图里，这 177 个标注是屏幕上最密的文字，却和轨道毫无关系；读者需要的方位信息，
经纬网已经提供了。所以标注被移除。

**为什么还留着。** 它是项目里唯一一处具备以下全部内容的来源：

- 约 40 种语言的国家名（`NAME_EN`、`NAME_ZH`、`NAME_JA` … 共 21 个我们用得上的语种列）；
- 主权与 ISO 3166 标识（`ISO_A2`、`ISO_A3`、`SOV_A3`）；
- 每个国家一个合理的标注锚点（最大环的质心，不是整个多边形的质心）；
- 以经纬度环表示的国界（`Polygon` / `MultiPolygon`）。

一旦某个视图需要标出地面站、落区或发射场——这些在本产品里都是运营方可见的对象——需要的正是这些字段。
重新下载只要一条命令，所以归档成本极低。

**解析器**：`src/lib/geo/countries.ts`。它解析原始文件、保留全部语言列，
是一个数据访问模块，不是渲染模块。
