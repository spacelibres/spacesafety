# 星座高度与碎片环境

高度决定一个星座处在什么环境里，而差别不是渐进的。

| 壳层 | 特征 | 对避撞意味着什么 |
|---|---|---|
| 600 km 以下的低轨 | 碎片密集，几年内衰减 | 交会频繁，但物体会自己离开 |
| 540–570 km | Starlink 所在壳层 | 交会率高，机动预算也高 |
| 极轨／太阳同步 500–800 km | 多个运营方共用 | 持续的穿越流量，多为短预警 |
| 中轨约 20 000 km | 导航星座 | 物体少，也没有阻力帮助：碎片能留上千年 |
| 地球静止轨道约 35 786 km | 定点经度、位置保持 | 交会罕见，但几何特殊（同槽位共存） |

## 这对 API 客户端意味着什么

交会率是壳层的属性，不是软件造成的。几百颗卫星在 550 km 的运营方，一天看到的 CDM
比静止轨道运营方一年看到的还多；对其中一方合适的轮询节奏，对另一方是错的。

本部署展示的编目为每个物体带一个 `regime` 分类，由根数推导而不是谁声称的，
所以"我这个壳层里有多少流量"是数据能回答的问题。

## 两条值得记住的推论

**碎片是局部的。** 780 km 的解体污染那一条带几十年；同样的解体发生在 300 km，
两年内就没了。把两者一视同仁地筛查，算术上没错，运行上会误导。

**穿越几何并不均匀。** 共面的邻居缓慢漂移，产生观测期很长的交会；极轨卫星穿过同一
壳层时，产生的是短预警交会。收到多少条 CDM，说明不了你面对的是哪一种。

## 用编目做背景

```bash
# 某个轨道类型的编目对象数
curl -s 'http://127.0.0.1:3000/api/v1/catalogue/choice?regime=LEO' | head -c 400
```

各轨道类型的数量变化很慢；你自己壳层里的数量突然变化值得追查，因为它通常意味着
一次解体，而不是一次发射。
