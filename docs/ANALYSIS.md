## 5. 一致性：两源根数是否描述同一轨道

### 5.1 方法

把两源根数用 SGP4 传播到**同一时刻**，把分离量分解为径向（轨道形状/半径）
与沿迹（相位）两个分量。径向小、沿迹大 = 同一条轨道、不同时刻的采样。

### 5.2 (a) Space-Track vs Spacebook entity/tle

只有 5 个对象历元不同，n = 5：

| 指标 | 中位 |
|---|---|
| 总分离 | 53.97 km |
| 径向分离 | **0.33 km** |
| 相位误差 | **0.12 min** |
| 历元差 | 20.45 h |

**结论**：即使历元差 20 小时，径向只差 0.33 km。两源数据一致。

### 5.3 (b) Space-Track vs Spacebook XP-TLE（真正滞后的源）

n = 2 993：

| 指标 | min | 中位 | p90 | p99 | max |
|---|---|---|---|---|---|
| 总分离 (km) | 4.05 | 664.18 | 1 341.58 | 3 280.44 | 14 929.46 |
| **径向 (km)** | 0.00 | **6.47** | 26.40 | 147.50 | 3 569.51 |
| 沿迹 (km) | 3.96 | 663.84 | 1 341.58 | 3 280.41 | 14 927.96 |
| 相位误差 (min) | 0.01 | **1.53** | 3.02 | 7.40 | 34.40 |
| 历元差 (h) | 5.10 | 53.02 | 64.40 | 95.09 | 157.72 |

分类占比：

| 判据 | 数量 | 占比 |
|---|---|---|
| 径向 <10% 总差（纯相位差） | 2 779 | **92.8%** |
| 径向 >50% 总差（轨道不同） | 32 | 1.1% |

按类别：

| 类别 | n | 总分离中位 | 径向中位 | 相位中位 |
|---|---|---|---|---|
| DEBRIS | 1 596 | 774.9 km | 8.2 km | 1.8 min |
| PAYLOAD | 929 | 566.8 km | 4.3 km | 1.3 min |
| ROCKET BODY | 468 | 720.0 km | 6.4 km | 1.6 min |

**结论**：

1. **92.8% 的差异是纯相位差**（径向 <10%），说明两源描述的是**同一条轨道**，
   只是观测时刻不同。表面 664 km 的差距**不等于数据错误**。
2. 有 **32 个对象（1.1%）径向占主导**，轨道本身不一致——这是需要人工核查的清单，
   不是可以忽略的噪声。
3. 碎片（DEBRIS）的径向误差（8.2 km）比载荷（4.3 km）大一倍，
   与"碎片无轨道保持、面质比建模差"一致，但**样本不足以区分是建模差异还是数据错误**。

## 6. 由此得出的使用规则（均有数据支撑）

| 规则 | 依据 |
|---|---|
| 必须双源（Space-Track + Spacebook） | Spacebook 独有 2 064 个对象（6.29%） |

| 碎片不得声称高精度 Pc | 15 680 个碎片中仅 6 个有质量（0.04%） |
| 碰撞截面必须用 DISCOS 实际值 | 截面各向异性平均 20 倍 |
| 32 个径向异常对象需人工核查 | 径向 >50% 总差，占 1.1% |

## 7. 数据不足、无法结论的部分

明确列出，避免被误读为"已验证"：

1. **物理参数的准确性**。DISCOS 的质量/截面来自运营方申报，本报告只统计了
   *有多少*，**没有验证其是否正确**——没有第三方基准可对照。
2. **32 个径向异常对象的成因**。可能是 NORAD 编号错配、可能是机动、
   也可能是某一源数据错误。**当前数据无法区分**。
3. **碎片径向误差偏大的原因**。样本 n=1 596，但缺少面质比与姿态数据。
4. **Spacebook 与 Space-Track 是否同源**。99.98% 历元完全相同，强烈暗示共享上游，
   但**没有直接证据**（无披露、无 trace 头）。
5. **长期演化**。目前只有 1–3 天的归档，**无法判断**某源是否在悄悄改写历史数据。
   这需要连续归档至少数周才能回答。

## 复现方式

```bash
npm run analyze                 # 完整分析（含传播，约 1 分钟）
npm run analyze -- --fast       # 跳过传播
npm run analyze -- --sample 5000
npm run analyze -- --json       # 机器可读
```

结果同时写入 `data/analysis-report.json`，可与其他日期的报告做 diff。
